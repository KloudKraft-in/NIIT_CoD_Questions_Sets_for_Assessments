# ITSM Lab: New-Hire Access Provisioning Batch - Service Request Catalogue RITM & SCTASK Execution

Duration : 30 Min.

## Scenario
Five new cloud engineering hires join the enterprise and require standard role-based access to GitHub Enterprise, AWS Development sandbox, and VPN access by end of day. The service desk analyst must navigate the ServiceNow Request Catalogue, validate approval workflows for elevated AWS permissions, execute the underlying Service Catalog Tasks (SCTASK), and verify that all Request Items (RITM) close in strict compliance with catalogue Fulfilment SLAs.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Distinguish Service Requests from Incident tickets and execute catalogue item requests.
- Trace multi-stage approval workflows and resolve a pending manager approval bottleneck.
- Fulfill and close all child SCTASKs and verify automatic cascade closure of parent RITM records.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Execution of standard catalogue request hierarchy (REQ -> RITM -> SCTASK) and tracking approval workflow states: 5 marks
2. Accurate completion and closure of individual SCTASK items within catalogue Fulfilment SLA: 5 marks

**Total Score: 10 Marks**
