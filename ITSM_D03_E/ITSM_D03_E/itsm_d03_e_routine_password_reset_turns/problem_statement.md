# ITSM Lab: Routine Password Reset Turns Into P3 - Priority Reclassification & Compliant Closure

Duration : 30 Min.

## Scenario
A routine P4 user request for a password reset uncovers that multiple user accounts in the regional sales department are locked due to an expired Active Directory service account token. The analyst must escalate and reclassify the ticket from a P4 service request to a P3 application access incident, recalibrate SLA tracking, record technical investigation logs in internal work notes, resolve the underlying AD token conflict, and close the incident with compliant Close Code and Close Notes.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Recognize the transition trigger from single-user request (P4) to multi-user department incident (P3).
- Update ticket priority in ServiceNow, triggering automated SLA target recalculation.
- Maintain professional separation between internal technical work notes and customer-facing communications.
- Close the ticket using verified standard Close Code and root cause resolution notes.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

3. Selection of compliant Close Code and detailed resolution summary satisfying quality standards: 3 marks
